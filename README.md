# norc-apt-site

Signed apt repository for `norc-cli` / `norc-desktop`, served at
https://apt.norc.app via GitHub Pages.

Populated by `packaging/apt/publish.sh` in the main
[norc](https://github.com/redcoatasher/norc) repo — see
`packaging/apt/README.md` there for the one-time GPG key + publish flow.
Do not edit files here by hand; they're regenerated by that script.
